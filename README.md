# iac_forge

Ansible collections for infrastructure as code, published under the `iacforge` namespace.

| Collection | Path | Install |
|------------|------|---------|
| `iacforge.snowflake_iac` | [ansible_collections/iacforge/snowflake_iac](ansible_collections/iacforge/snowflake_iac) | `ansible-galaxy collection install iacforge.snowflake_iac` |

Issues: please name the collection in the title, e.g. `[snowflake_iac] grant fails on ...`.
